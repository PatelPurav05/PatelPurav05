# Hi, I'm Purav

I'm the co-founder of [Clayzo](https://clayzo.com), an animation engine built for coding agents. Claude Code, Codex and Cursor use it to write motion graphics and interactive animations as typed documents, check their own frames, and ship them to play live on the web or natively on iOS and macOS.

The banner above is Clayzo too: an agent wrote it as [one TypeScript file](./banner/author.ts) and exported it to GIF. To try it, run `npx clayzo@latest init` and ask your agent for an animation in a sentence.
